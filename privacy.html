プライバシーポリシー

ModGarage(以下「本アプリ」)は、運営者 Ryota Masuda(以下「運営者」)が提供する、車とバイクの改造後の姿をAIで作るアプリです。本アプリでどの情報を扱い、どこへ送り、いつ消すかを次のとおり定めます。

1. 改造後の画像を作るために送る写真

選んだ写真は、改造後の画像を作るときだけ運営者の中継サーバー(Cloudflare 上で動かしています)を経由し、Google LLC の Gemini API(米国)へ送ります。送るのは、利用者がナンバープレートの上を指でなぞって黒く塗った後の写真と、選んだ車種・改造の内容・一言の欄に書いた内容から作る指示文です。写っている車のメーカー・車名を入力した場合も、作品の一覧で見分けるためだけに端末の中で使い、外部へは送りません。

運営者は有料版の Gemini API を使います。Google の規約(Gemini API 追加利用規約)では、有料版で送った写真と指示文、できあがった画像は Google の製品の改善に使われません。ただし Google は、禁止された使い方を見つけるために、これらを一定の期間記録します。

中継サーバーは送られた写真や指示文を保存しません。できあがった画像はこの端末の中だけに保存され、運営者のサーバーには残りません。写真の撮影場所や撮影日時(Exif情報)は読み取りません。

2. ナンバープレートを隠す仕組み

利用者が黒く塗った範囲は、送信前の写真とできあがった画像の両方で塗りつぶします。あわせて、塗り忘れたナンバープレートが写っていないかを Gemini API に確かめさせ、残っていればその位置をアプリへ返して確認画面に戻します。塗る前の写真をナンバープレートの位置を探す目的だけで外部へ送ることはしません。

3. 外部へ送るそのほかの情報

  • RevenueCat, Inc.(米国の会社): 購入の状態を管理するために、本アプリが端末ごとに作る匿名の識別子と、購入した商品・期限などの購入の記録を送ります。メールアドレスや氏名は送りません。
  • Functional Software, Inc.(米国の会社、Sentry): 本アプリが想定外の止まり方をしたとき、不具合を直すために、操作の種類を示す名前(画面を開いた、写真を選んだ、生成を始めたなど)、起きた場面を示す符号、端末の機種と OS の版を送ります。「この画像を報告」を押したときは、選んだ問題の種類、作品の受付番号、選んだ改造の候補の番号、一言の欄に記入があったかどうかを送ります。写真の中身、一言の欄に書いた文章、生成に使った指示文は送りません。
  • Apple と Google: 購入は App Store と Google Play の仕組みで行います。

4. 中継サーバーが一時的に持つ情報

中継サーバーは、匿名の識別子ごとの当日の生成回数と、接続元を示す符号(接続元のIPアドレスを塩付きハッシュに変えたもの)ごとの当日の回数を、不正な集中利用を防ぐために持ちます。どちらも翌日になると自動で消え、利用者が個別に消すことはできません。写真そのものは、この回数の記録には含みません。

米国の個人情報の保護の制度は、個人情報保護委員会のページ(https://www.ppc.go.jp/enforcement/infoprovision/laws/)で読めます。広告は表示せず、広告のための追跡もしません。

5. 使う目的

改造後の画像を作ること、1日に使える回数を数えて不正な集中利用を防ぐこと、購入の状態を管理すること、不具合と不適切な生成を直すこと。これ以外の目的には使いません。

6. 消し方

アプリの「設定」の「すべてのデータを削除」で、端末の中の作品の画像と設定をすべて消します。アプリを削除しても消えます。RevenueCat の購入の記録は、Apple と Google の購入の記録と結び付いているため、本アプリからは消せません。消したい場合は下のメールアドレスへご連絡ください。

7. 対象の年齢

本アプリは18歳以上の方を対象にしています。画像生成に使う Gemini API の利用条件により、18歳未満の方は使えません。
